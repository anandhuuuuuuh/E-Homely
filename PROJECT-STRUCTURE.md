# E-HOMELY — Structured Project

This version reorganizes the uploaded E-HOMELY files into a maintainable web-project structure.

## Important

The uploaded files did not include the original `assets/` images or the actual Phase 2/Phase 3 source files. Therefore this ZIP does **not** invent or replace those implementations. Add the original assets into `assets/images/` and replace the Phase 2/Phase 3 placeholders with their existing source files.

## Structure

- `index.html` — Home page
- `css/` — shared styles
- `js/` — shared/page JavaScript
- `pages/categories/` — Categories page
- `pages/phase2/` — Phase 2 page location
- `pages/phase3/` — Phase 3 page location
- `assets/` — images, icons and fonts
- `data/` — menu/data files
