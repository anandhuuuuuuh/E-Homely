E-HOMELY - Structured Project

Project structure:
- index.html: Home page
- pages/categories.html: Food categories
- pages/menu.html: Menu and cart
- pages/checkout.html: Checkout and token
- css/: Page-specific stylesheets
- js/: Page-specific JavaScript and shared chatbot
- assets/images/: Website/hero/category images
- assets/food/: Food menu images
- docs/: Project documentation

All local image references use project-relative paths so the project works on another computer after opening in VS Code.
